# Claude Instructions

This file contains custom instructions for the Claude AI assistant working on this project.

## Project Context

- **Framework**: Next.js with TypeScript
- **Package Manager**: npm
- **Build System**: Next.js with ESLint, PostCSS

## Development Guidelines

1. Use the `app/` directory for Next.js App Router pages and layouts
2. Store reusable components in `components/`
3. Put utility functions and helpers in `lib/`
4. Keep logs in the `logs/` folder
5. Static assets go in `public/`

## Code Style

- Follow ESLint configuration
- Use TypeScript for type safety
- Format code consistently
